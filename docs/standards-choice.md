# Какой стандарт брать

Развилка одна и решается в самом начале: вы сдаёте автоматизированную систему или программное средство. От ответа зависит структура ПМИ, набор разделов и половина терминологии.

## Коротко

Автоматизированная система, то есть система из людей, процессов, технических средств и программного обеспечения, разворачиваемая у заказчика на его инфраструктуре, идёт по комплексу 34. ПМИ строится по ГОСТ Р 59795-2021 п. 5.13, виды испытаний по ГОСТ Р 59792-2021.

Программное средство, которое передаётся как продукт, без обязательств по объекту автоматизации, идёт по ЕСПД. ПМИ строится по ГОСТ 19.301-79.

Пилотное внедрение продукта у заказчика почти всегда первое. Даже когда предмет договора звучит как «поставка лицензий», испытания идут на стенде заказчика, проверяется соответствие ТЗ, подписывается акт, и комиссия ждёт документ по 34-му комплексу.

## Сравнение структуры

| ГОСТ Р 59795-2021 (АС) | ГОСТ 19.301-79 (ЕСПД) |
| --- | --- |
| Объект испытаний | Объект испытаний |
| Цель испытаний | Цель испытаний |
| Общие положения | — |
| Объём испытаний | Требования к программе |
| — | Требования к программной документации |
| Условия и порядок проведения испытаний | Средства и порядок испытаний |
| Материально-техническое обеспечение | — |
| Метрологическое обеспечение | — |
| Отчётность | — |
| Приложения (тесты) | Методы испытаний, приложения |

Документ по ЕСПД заметно короче. Соблазн взять его вместо тяжёлого документа по 34-му комплексу понятен, но он оборачивается разговором на приёмке: комиссия открывает ТЗ, видит ссылку на комплекс 34 и просит недостающие разделы.

## Как решить за пять минут

Посмотрите на ТЗ. Если оно составлено по ГОСТ 34.602, вопрос закрыт: комплекс 34. Если ТЗ на программу и в нём есть требования к программной документации по ГОСТ 19.101-77, это ЕСПД.

Дальше посмотрите на предмет испытаний. Проверяется ли квалификация персонала, готовность пользователей, работа в режимах эксплуатации у заказчика? Это признаки автоматизированной системы.

И посмотрите, кто подписывает акт. Приёмочные испытания АС проводит комиссия, назначенная заказчиком, и программу утверждает заказчик. Если по договору достаточно подписи руководителя проекта со стороны исполнителя, речь скорее о передаче программного средства.

## Что делать, когда стандарты смешаны в одном проекте

Такое бывает: система по комплексу 34, а отдельные её компоненты поставляются как программные средства со своей документацией по ЕСПД. Тогда ПМИ на систему пишется по ГОСТ Р 59795-2021, а автономные испытания компонентов закрываются собственными документами по ГОСТ 19.301-79. Ссылки на эти документы идут в раздел «Ранее проведённые испытания».

Чего делать не нужно: собирать один документ из разделов обоих стандартов. Получится структура, которой нет ни в одном из них, и первый же нормоконтроль вернёт документ на доработку.
