# Чек-лист перед сдачей ПМИ

Проходить целиком, по порядку, с открытым документом. Пункт считается пройденным, когда вы своими глазами увидели результат, а не решили, что он должен быть таким.

## Полнота по стандарту

- [ ] Все восемь разделов ГОСТ Р 59795-2021 на месте: объект испытаний, цель, общие положения, объём, условия и порядок, материально-техническое обеспечение, метрологическое обеспечение, отчётность.
- [ ] Если раздел объединён с другим или исключён, его содержание действительно изложено в другом разделе. Вырезать раздел без переноса содержания стандарт не разрешает.
- [ ] В разделе «Общие положения» присутствуют все пять блоков, включая перечень ранее проведённых испытаний.
- [ ] Шесть обязательных проверок по п. 3.13 ГОСТ Р 59792-2021 включены в перечень, в том числе проверка квалификации персонала и требований безопасности.
- [ ] Для приёмочных испытаний перечень требований дан со ссылками на пункты ТЗ (п. 6.1), реквизиты ответственных за проведение указаны.
- [ ] Тесты приложены (п. 3.7). Для предварительных испытаний приложен график.

## Связность

- [ ] Каждая проверка из перечня имеет методику в разделе 9. Пересчитайте строки, а не оцените на глаз.
- [ ] Каждая методика соответствует существующей проверке. Обратное направление проверяется отдельно.
- [ ] Идентификаторы совпадают: П-01 в перечне, П-01 в методике, П-01 в матрице соответствия, П-01 в форме протокола.
- [ ] Каждая проверка ссылается на пункт ТЗ, и такой пункт в ТЗ существует. Откройте ТЗ и убедитесь.
- [ ] Все требования ТЗ, попадающие в объём этих испытаний, закрыты проверками.
- [ ] Ссылки на разделы внутри документа ведут туда, куда написано. После любой перенумерации проверяются заново.

## Формулировки

- [ ] Нет критериев вида «работает корректно», «в полном объёме», «удовлетворительно». Каждый критерий проверяем.
- [ ] Числовые значения совпадают с ТЗ дословно. «Около 105» не превратилось в «105».
- [ ] Нет решений, приписанных сторонам. Ограничения сформулированы как ограничения документа.
- [ ] Нет сущностей, которых нет в разделе с терминами и сокращениями.
- [ ] Каждое сокращение из таблицы встречается в тексте, каждое сокращение из текста есть в таблице.

## После массовых правок

Отдельный проход, если вы переименовывали группу требований, перенумеровывали разделы или гоняли замену по всему документу.

- [ ] Ссылок на старые идентификаторы не осталось. Грепом по всему файлу, включая приложения и таблицы.
- [ ] Диапазоны («проверки П-01…П-12») пересчитаны после добавления или удаления строк.
- [ ] Названия групп соответствуют их новому статусу. Группа, ставшая обязательной, больше не называется опциональной.
- [ ] Оглавление пересобрано, номера страниц соответствуют.

Массовая замена стабильно порождает дефекты второго порядка. Один прогон `sed` по документу однажды дал восемь новых ошибок: висящие ссылки, устаревшие диапазоны и группу, оставшуюся с прежним названием. Проверять после такой правки нужно весь документ, а не изменённые места.

## Ответы рецензентам

- [ ] Перед фразой «учтено в п. X» вы открыли пункт X и увидели правку. Каждый раз, а не выборочно.
- [ ] Замечания перенесены из оригинала посимвольно, без своей редактуры.
- [ ] Замечаний, которых рецензент не писал, в реестре нет.

## Безопасность и конфиденциальность

- [ ] Пароли, токены, ключи не написаны литералом. Только подстановки, которые испытатель задаёт перед прогоном.
- [ ] Параметры стенда вынесены в лист готовности и передаются отдельно.
- [ ] Прогнан список из docs/confidentiality.md: внутренние адреса и FQDN, подсети, ИНН и ОГРН, серийные номера, имена системных служб, реквизиты физических лиц.
- [ ] Грепы прогонялись с нормальной локалью. Первый чистый результат перепроверен вручную: греп, упавший на кодировке, показывает «чисто» и на грязном файле.

## Оформление и версия

- [ ] Все заглушки `{{...}}` заполнены: `grep -o '{{[^}]*}}' файл` не выдаёт ничего.
- [ ] Пояснения «Как заполнять» вырезаны: строк, начинающихся с `>`, в документе не осталось.
- [ ] Версия отражена и в имени файла, и в титуле, и в листе регистрации изменений. Три места, одно значение.
- [ ] В листе изменений факты, а не заглушки про «перечень заполняется при выпуске».
- [ ] Оглавление собрано, битых ссылок нет.
- [ ] Если документ выпускается в .docx: файл открыт в настоящем Microsoft Word, а не только в LibreOffice. Расхождения по нумерации, полям и оглавлению видны именно там.
